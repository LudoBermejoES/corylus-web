Privacy

Corylus collects no personal data. This page explains what that means in practice, and names every third party your device talks to because of something Corylus does.

Last updated 2 November 2026.

What Corylus collects

Nothing.

Corylus is a desktop and mobile writing application. It has no user accounts, no telemetry, no analytics and no crash reporting. There is no Corylus server for it to send anything to. Your documents are plain Markdown files in a folder you chose on your own device, and they stay there.

Optional downloads

Some features are optional downloads: a grammar engine, natural read-aloud voices, dictionaries and thesauruses. When you choose to install one, your device fetches it from Hugging Face or GitHub. Those providers see the request, as they would for any download. Corylus sends them nothing about you or your writing, and the components run entirely on your own machine once installed.

Synchronisation

Sync is optional and off by default. If you turn it on, your files go to a destination you configure and control — your own WebDAV server, Dropbox or Google Drive. Corylus is not a party to that transfer and keeps no copy. Your credentials for that service are stored in your operating system's keychain, never in the project and never transmitted anywhere else.

Updates

On desktop, Corylus checks a static file on GitHub to see whether a newer version exists. That request reaches GitHub, which sees your IP address as it would for any web request. The check sends no identifier of any kind, and it can be switched off in Settings.

This website

This site is hosted on GitHub Pages. It sets no cookies and runs no analytics. GitHub records server logs, including IP addresses, under its own privacy policy. The site loads fonts from Google Fonts, which means Google serves those font files and sees the request.

Children

Corylus is not directed at children and collects no information from anyone, of any age.

Changes

If this policy changes, the new version appears on this page with a new date. Since Corylus collects nothing, a change here would most likely mean a new optional component with its own download source.

Contact

Questions about this policy: open an issue on the project's GitHub repository.
